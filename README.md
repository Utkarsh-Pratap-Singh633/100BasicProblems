# 100 Programs — Building My Problem-Solving Foundation


## 📌 About

- **Goal:** Build core problem-solving ability through repetition and structured difficulty progression.
- **Language:** `<Python / Java / C++>` — pick one and stick with it for all 100.
- **Rule:** Solve strictly in order — easiest to hardest. No skipping ahead.
- **Convention:** Wherever `n` appears in a problem, it is read as user input.

## 📋 Rules I'm Following

1. One language for all 100 problems — no switching midway.
2. Solve in order — the sequence is deliberately easy → hard.
3. No looking up solutions first. Struggle for 10–15 minutes before searching.
4. Type every solution myself — no copy-paste.
5. After solving, ask: *"Can I do this with fewer lines or cleaner logic?"*
6. Read `n` as input wherever it appears.
7. Tick off each problem after solving it.
8. Target: 3–5 problems/day → done in about a month.
